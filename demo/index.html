WordPress 7.1.3 Vulnerable Baseline

Staging Directory Path: SOURCE-VERIFIED 

wp-content/upgrade/wordpress/

Predictable for the tested wordpress.zip package name (derived from package filename, not hardcoded by core).

Guard File Cleanup: SIMULATED

Guard Stripped clean_working_dir() unconditionally deletes all files, including index.php, exposing directory listing if web server is unhardened.

File Promotion Boundary: SIMULATED 

$skip = array( 'wp-content', 'wp-includes/version.php' );

Missing exclusion rule. Relative-path sync models nested rules; staged wp-config.php is promoted into production root.

Note: Pre-unpack cleanup and configuration overwrite demonstrations are filesystem simulations of source logic, not active WordPress update captures.

WordPress 7.1.4 Patched Protections

Staging Directory Path: SOURCE-VERIFIED 

wp-content/upgrade/wordpress-weIdh9kF3Kd71Nkj/

Appends 16-character pseudo-random alphanumeric suffix via get_working_dir_name(). ILLUSTRATIVE token shown.

Guard File Cleanup: SIMULATED

Guard Preserved & Auto-Created Preserves existing index.php during pre-unpack cleanup and auto-generates empty guard file if absent.

File Promotion Boundary: SIMULATED 

$skip = array( 'wp-content', 'wp-includes/version.php', 'wp-config.php' );

Explicit exclusion rule. Staged wp-config.php is strictly dropped by relative-path sync, preserving existing production config.

Note: Token strings are illustrative; WordPress core calls wp_generate_password(16, false) in production runtime.
