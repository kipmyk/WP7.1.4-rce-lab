# Phase 5 HTTP Response Captures: Upgrade Directory Interactions

This document compiles the raw HTTP headers and response codes captured when interacting with endpoints within the `wp-content/upgrade/` hierarchy on WordPress 7.1.3 and 7.1.4.

---

## 1. Directory Root Interaction (`/wp-content/upgrade/`)

### Case A: Without `index.php` Guard File
```http
GET /wp-content/upgrade/ HTTP/1.1
Host: 127.0.0.1:8081
User-Agent: curl/8.9.1
Accept: */*

HTTP/1.1 403 Forbidden
Date: Sun, 01 Nov 2026 05:23:28 GMT
Server: Apache/2.4.69 (Debian)
Content-Length: 316
Content-Type: text/html; charset=iso-8859-1

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">
<html><head>
<title>403 Forbidden</title>
</head><body>
<h1>Forbidden</h1>
<p>You don't have permission to access this resource.</p>
</body></html>
```
* **Observation:** Both 7.1.3 and 7.1.4 return `403 Forbidden`.
* **Technical Note:** This status is generated by Apache's default Debian configuration (`Options -Indexes`). It is not an application-level control.

---

### Case B: With `index.php` Guard File Present
```http
GET /wp-content/upgrade/ HTTP/1.1
Host: 127.0.0.1:8081
User-Agent: curl/8.9.1
Accept: */*

HTTP/1.1 200 OK
Date: Sun, 01 Nov 2026 05:23:37 GMT
Server: Apache/2.4.69 (Debian)
X-Powered-By: PHP/8.2.35
Content-Length: 0
Content-Type: text/html; charset=UTF-8
```
* **Observation:** Returns `200 OK` with 0 bytes body.
* **Technical Note:** Confirms that Apache resolves the `DirectoryIndex index.php` and executes the guard script, outputting silence.

## 2. Direct Static File Retrieval (`/wp-content/upgrade/probe.txt`)

```http
GET /wp-content/upgrade/probe.txt HTTP/1.1
Host: 127.0.0.1:8081
User-Agent: curl/8.9.1
Accept: */*

HTTP/1.1 200 OK
Date: Sun, 01 Nov 2026 05:24:29 GMT
Server: Apache/2.4.69 (Debian)
Last-Modified: Sun, 01 Nov 2026 05:24:29 GMT
Content-Length: 24
Content-Type: text/plain

BENIGN_STATIC_PROBE_713
```
* **Observation:** Files in `wp-content/upgrade/` are directly readable over HTTP when the path is known.

## 3. Direct PHP Script Execution (`/wp-content/upgrade/probe.php`)

```http
GET /wp-content/upgrade/probe.php HTTP/1.1
Host: 127.0.0.1:8081
User-Agent: curl/8.9.1
Accept: */*

HTTP/1.1 200 OK
Date: Sun, 01 Nov 2026 05:25:20 GMT
Server: Apache/2.4.69 (Debian)
X-Powered-By: PHP/8.2.35
Content-Length: 25
Content-Type: text/html; charset=UTF-8

PROBE_PHP_EXEC_ACTIVE_713
```
* **Observation:** The web server executes PHP scripts inside `wp-content/upgrade/` by default.
